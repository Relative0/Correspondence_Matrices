# CM notation standard v1

Status: active project convention.
Effective: 2026-09-12.

## Logical exclusive-or

The canonical CM symbol for logical exclusive-or is:

- rendered text: `⇕` (Unicode U+21D5, UP DOWN DOUBLE ARROW)
- LaTeX: `\Updownarrow`
- spoken or explanatory prose: “exclusive-or”; “XOR” may be used as its familiar name

Do not use `⊕` or `\oplus` for logical exclusive-or in new or revised CM papers, scripts, captions, storyboards, visual specifications, or videos. This distinction is required because those symbols have separate logistical uses in the CM materials.

Frozen review and production packages remain immutable evidence. Apply this convention by creating successor versions and record any retained historical occurrence as superseded.
