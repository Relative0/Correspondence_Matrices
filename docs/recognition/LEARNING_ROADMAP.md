# CRSE learning implementation roadmap

The [machine-readable register](experiment_register.json) preserves R01-R18,
the full transformation inventory, and all eight application families from the
owner's implementation brief. An implemented interface is not a measured track.
No model is promoted; Windows launcher, containment, deployment and general
cloud product work remain deferred. D8 is one bounded authorized Linux
confirmation. Existing historical evidence remains unchanged.

A/B, six bounded slices of C, nine bounded slices of D, and two bounded slices
of E are implemented
and measured. C includes actual
matrix MLP, CNN, GNN, fused, and contrastive retrieval training plus a frozen
EPFL evaluation slice. Its synthetic representation signal passed, retrieval
missed its threshold, and EPFL transfer was poor. C2 adds an exact balanced
cofactor XOR-decomposition teacher, canonical factor witnesses, mixed n=4/6/8
training, and held-out n=10 confirmation. Its four matched variable-size model
families failed the predeclared representation and size-transfer criteria; the
exact detector was perfect and the frozen EPFL slice again had no positives.
C3 replaces that all-negative slice with a full local EPFL scout: 894 of 9,060
eligible natural cones satisfy an exact arbitrary-variable XOR decomposition.
The frozen 188-function dataset is balanced and circuit-disjoint over n=4-10.
A source-DAG GNN and ANF-interaction multitask GNN did not pass both-seed test
and development-confirmatory criteria. Validation-only minimum-cut decoding
improved proposals but accepted only 6.25-27.8% of positive held-out cases.
A 94-pair same-circuit structure-matched repeat reduced most scores toward
chance. Exact verification remained perfect and no neural path was promoted.
C4 then supervised complete canonical cuts and added a same-circuit margin loss.
Ranking reached 0.833-0.889 on confirmatory circuits but only 0.375-0.500 on the
held-out square circuit. Graph accepted-positive recall remained 0.000-0.222,
and charged safe inference was 4.6-6.0x slower than exact ANF. The formulation
improved, but transfer, partition and cost criteria still failed safely.
C5 replaced the global cut head with bidirectional context-rich variable
embeddings and one shared scorer. Fixed-anchor permutation equivariance passed
exactly, and the no-ranking arm improved confirmatory BA to 0.750-0.778, but
held-out test transfer and learned cost still failed. An exact symbolic source-DAG
ANF control then achieved perfect classification and 1.22-1.58x median gains over
truth-vector ANF, while a 63.7 ms confirmatory p95 tail failed the bounded cost
criterion. A cached bitset symbolic hybrid is now the immediate opportunity.
C6 implemented that opportunity with a 1,024-bit maximum packed coefficient
vector, exact subset-transform multiplication, bounded exact product caching,
and a validation-frozen truth-vector fallback. The packed cores achieved
1.28-1.64x held-out median and 1.80-2.18x p95 gains with zero mismatches. The
hybrid missed confirmatory p95 by 1.4%; independent-family and cross-machine
confirmation now apply to the frozen packed core, while the gate remains off.
D now measures four separate
task contracts through direct, CSE, CM-IR and explicit dense-CM paths, a fitted
task/query router, exact caching, and stop/one-rewrite scheduling on a new EPFL
slice. Routing gains were task-specific; dense-CM construction and per-instance
rewrite proof were negative results. These are measured smokes, not broad
graph-learning or transformation/reuse completion. D2 now proves one AIG-XOR
motif over Boolean metavariables and reuses a fixed structural matcher. It beats
repeating explicit CM proof, including at five internal sites in two EPFL cones,
but still loses to the no-rewrite CSE control. D3 adds a second proved rule,
deterministic overlap priority, and exact changed-cone invalidation across three
generated DAG versions. Persistent caching halves fresh rematching cost on
sparse changes but still loses to no rewrite. D4 adds a third proved factoring
rule, a pre-identity reuse gate, serialized provenance, and adversarial cache
controls. It reduced matching overhead but the generated workload had only 1.7%
cached-oracle headroom. D5 froze that gate on 32 previously unused EPFL cones at
support 9-12: the three-session sequence achieved a small 1.030x gain over no
rewrite, with cold loss and 1.156-1.168x warm-session gains. This is one-machine
evidence, not production promotion. Actual related natural revisions and Linux
confirmation are now measured; another source, CM decomposition, and E remain
pending. The
[optional framework request](NEURAL_DEPENDENCY_REQUEST.md) was approved and
executed in an isolated environment.

D6 then exercised exact identity and invalidation on 120 bounded relations from
20 actual adjacent feature-model transitions. Forty-one sources were safe hits
and 79 invalidated; 76 unchanged outputs came from changed sources and were
correctly refused. Caching was 1.015x over fresh CM, while direct conditioned-CNF
evaluation remained about 10.94x faster. D7 added strict multi-pass termination,
cycle detection and overlap refusal. It exposed 18 later factoring applications,
but fixpoint normalization lost to both one pass and no rewrite. The reused-slice
one-pass 128-use arm achieved 1.050x. D8 reproduced exact outputs and the same
451 rule applications on Linux, but measured only 0.929x versus no rewrite. The
profitability criterion failed and unconditional one-pass promotion was refused.
D9 then trained a machine-calibrated bounded cost tree only on circuit-disjoint
depth/control BLIF cones and froze it before loading validation or size/evaluation
BLIF. The policy correctly collapsed to no rewrite, abstained on all 33 evaluation
workloads, and preserved zero semantic mismatches. Unconditional one pass found
43 exact factoring applications but measured only 0.429x the no-rewrite control;
the charged all-abstain gate measured 0.982x. Safety and leakage control passed,
profitability failed, and production promotion remains refused.

E1 implemented exact BDD SAT/count/restriction/equivalence artifacts with
deterministic persistence and charged order selection. First occurrence led;
best-of-k search and the learned timing policy were negative. E2 now implements
exact CNF, SAT, assumptions, resident sessions, equivalence miters, trusted
UNSAT replay, witness/core checking, safe invalidation, phase/order controls,
and a bounded execution policy. All frozen outputs matched direct truth, CM/CSE,
BDD, and CaDiCaL on task-equivalent status vectors. The tree learned the useful
fresh-versus-resident distinction but cost 1.0420x the sealed best fixed action
after advice overhead. Its local second-machine gate failed; no cloud run or
production promotion followed.

## Evidence rules

Every run requires an explicit finite manifest before execution and a fresh,
ignored output directory. Keep raw rows, models, split IDs, exact checks,
source/data hashes, environment, and incomplete records. Training/validation,
exploratory tests and sealed confirmation are distinct. More rounds on one
formula or more syntactic variants of one function are not independent samples.

CM means dense local truth-function input in the teacher; the original `cm`
portfolio arm means CM-IR simplification followed by the bigint executor.
Truth input construction is charged when starting from an expression. Accepted
replacements require independent exact checking, including its cost. One switch
disables learned advice and restores the same exact result contract.

Generated mechanism demonstrations are not natural-domain generalization.
No dependency installation, download, API call, commit, push, or publication
is implied by this roadmap. Group any future resource requests by exact package,
revision, license, size, local destination, effects, and finite compute budget.
