# RunPod native-scout V8 watchdog-binding amendment

Date: 2026-08-29  
Status: authorized by the user's bounded retry instruction

V8 completed authenticated read-only preflight and then failed locally before
creation. Its wrapper invoked the inherited watchdog launcher, whose module
`__file__` still named the frozen V7 controller. The subprocess therefore
refused against V7's already-used output directory. `RUN.json` records
`creation_attempted=false`, `pod_created=false`, and zero uploaded files; the
local output is preserved as `native-procfs-v8-001`.

V9 changes only the local watchdog binding: the inherited controller module's
runtime `__file__` is bound to the V9 wrapper before the watchdog is armed, so
the watchdog relaunches the same V9 code and output identity. The bounded
read-only upload-status 404 retry from V8 is unchanged. Cloud resources,
payload, dependency hashes, tests, zero-volume requirement, phase cap,
aggregate `$10` campaign ceiling, deadlines and ownership-only cleanup are
unchanged. This controller performs exactly one create request.
