# Historical naming and forward contract

Frozen `bnet_cm_scalar` / biology “scalar adapter” means brute-force enumeration over parsed BNet update functions. It does not construct or evaluate a CM. Its AEON comparison is comparator evidence, not a CM speedup experiment. Keep the original arm string when retrieving old ledger cells or verifying their hashes; show `bnet_scalar_oracle (historical bnet_cm_scalar)` when explaining them.

New code uses `cmbench.biology_controls.bnet_scalar_oracle`, which returns an exact count and one original-equation-checked witness. New rows use the `cm-biology-attribution-result/v1` structural contract and an explicit `mechanism_attribution` object. Historical analysis/campaign scripts remain replay tools for their frozen schemas, not templates for a new CM-specific experiment.

Packed affine elimination, disjoint-support/factorized arithmetic, bucket elimination, positional masks and indexed binding are CM-associated engineering outcomes using general algorithms. Attribute a CM-specific effect only after a matched ingress/representation ablation; changing solver or algorithm does not isolate it. The claim register supplies the permitted wording for each material existing result.

All corrections in this audit are successor/addendum files. Existing campaign results, source snapshots, manifests, reports and hashes were not rewritten.
