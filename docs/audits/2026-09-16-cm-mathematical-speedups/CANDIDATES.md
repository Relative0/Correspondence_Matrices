# Ranked exact-algorithm candidates

Read with the [decision report](REPORT.md) and its primary-source bibliography. **A1 alone is selected for Phase 2.** Ranking reflects present evidence and the cost of obtaining a decisive answer, not theoretical power. Every row below is a hypothesis unless explicitly labeled implemented or measured.

## Notation and shared accounting

`N,E`: source DAG nodes/edges; `I`: actual lowered primitive operations; `k`: unfixed ambient variables; `L_k=ceil(2^k/W)`: packed machine words; `S`: compiled representation size; `v`: peak live full-size buffers; `c`: retained cuts per node; `w`: cut width; `s`: separator/elimination width; `r`: algebraic rank; `m`: monomial count; `h`: dependency region visited after a change. Bigint operations on counts of up to `2^k` cost arithmetic on up to `k+1` bits, not unit time.

`P=O(N+E)` denotes ordinary admitted DAG parsing, not expanding a shared DAG into a tree. If an input is already dense, parsing itself must read `2^k` entries. `F` denotes full output: at least `L_k` word writes and `ceil(2^k/8)` delivered packed bytes, or `2^k` bytes for a dense Boolean array. Full output can dominate every candidate. Scalar output has only its actual integer/Boolean/witness size. Never compare scalar output with a full relation as if they were the same task.

`BE` is the report's fully charged break-even calculation. **Every row has no finite amortization break-even for extra setup if its steady-state execution plus required per-query output is not faster than its best matched control.** No row currently has a measured positive break-even. Memory includes metadata, live temporaries and retained output, not just the compressed payload.

## 3. Shortlist and commitment

1. **A1: proceed to the frozen local experiment.** A small finite proof domain and static residuals make failure inexpensive to establish. Retain the negative C36 cohort and rule-pack controls. This is not a production promotion.
2. **A2: defer until a real consumer provides the original/projected variable contract and a resident request trace.** Stay with existing exact APIs meanwhile. No synthetic domain campaign is justified merely to manufacture a use case.
3. **A3: defer until a supplied hierarchy and compact relation/query contract exist.** A theorem about a special repeated family is not evidence about the present benchmark corpus.

All other candidates remain below these or repeat completed/negative work. Stop this research turn after delivering the frozen design; do not implement several speculative backends in parallel.
