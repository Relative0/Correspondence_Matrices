# Protocol v5: selected EPFL natural secondary timing

Fixed on 2026-09-26 before this run's natural-case measurement. One excluded ABC command smoke on case 0 checked the coarse `time` output before this freeze; it supplied no reported timing result. That smoke rewrote its AIG because ABC embeds a timestamp; the exact originally frozen bytes were restored and the 196-file extension manifest and 71-case correctness freeze passed again before preparation. This is a **descriptive secondary study**, not a new primary confirmation. The prospectively frozen v4 synthetic primary utility rule failed and no natural finding may replace or pool with it. The 71 original EPFL primary-output cones, selection rule, translated ASTs, exhaustive BLIF oracle, ABC AIG correctness gate, and CM root outcomes are fixed in `../04_NATURAL_CIRCUIT_EXTENSION_20260926/`. All 71 cases remain in the run, including exceptions and timeouts. They share nine source designs and overlap prior P1--P14 families; no population-general or independent-family inference is claimed.

For each case, the common output is the full packed truth bitset on its 2--12 support variables in frozen support order. The bit at integer position `k` corresponds to assignment bit `j` of `k` for support variable `j`. The direct arm clears the bitset-environment cache outside its timer, builds the environment inside the timer, and calls the identity-memoized `eval_expr_bitset` on the unchanged AST. The CM arm clears composition, normalization, bitset-environment, and persistent-IR caches outside its timer. Inside the timer it calls `compile_expr_to_cm_pair_token(..., strategy="hybrid")` with row `x0`, columns `x1...`, and no fixed variables. A returned token is expanded to the full bitset by `cm_token_value`; if no token is returned, the unchanged original AST is compiled to ordinary CM IR and evaluated with `eval_cm_node_bitset`. The fallback construction and evaluation are inside the CM timer. Both arms verify the complete bitset against the source oracle after every timed invocation. Imports and AST construction are excluded from the producer timers and recorded separately. This matched full-bitset endpoint differs from v4's four-bit token endpoint.

Cases run sequentially in fresh Python processes. Check correctness, then warm each arm once. Estimate each arm from three untimed throwaway calls, set `ceil(100 ms / estimate)` inner calls capped at 100,000, and run a throwaway calibration block. If that block is below 100 ms, increase once toward 150 ms using its measured per-call time. A remaining sub-100 ms block is a recorded calibration failure. For 15 paired repetitions per case, randomize arm order with `Random(202610050000 XOR case_index)`. Clear the documented caches before each inner call outside its timer. Record each call's timed sum, per-call mean, loop count, root outcome, order, and calibration. The case process timeout is 60 seconds. Record process peak working set separately in a fresh process per case and arm, including common imports and expression construction. The 60-second limit also applies to each memory process. Power scheme and affinity are recorded before and after the run; no claim of control is made if they differ or cannot be verified.

An ABC-compatible arm is mandatory for all 71 translatable cases. The pinned ABC binary from the natural extension runs once per case/repetition in a fresh subprocess with exact commands `read_blif {cone}; time; strash; time; dc2; time; write_aiger {temporary_aig}; time`, 15 repetitions, one untimed warm-up, and a 60-second case-process timeout. Record whole subprocess wall time, the four coarse ABC `time` diagnostics for import, strash, dc2, and export, and separately measure Python AIGER parse plus exhaustive simulation. Truth is checked against the original BLIF after every repetition. The subprocess wall includes ABC startup and output serialization and is **not compared as a ratio** to resident Python arm producer times. The Python AIGER simulation is not represented as native ABC query latency. The coarse ABC phase times may round to 0.00 seconds and are diagnostics only. ABC process peak memory is not measured in this extension, so the full protocol-v3 systems comparison remains incomplete.

No hypothesis test, p-value, multiplicity correction, or utility-success threshold is applied. Report case-median direct/CM producer ratios descriptively for all cases and separately for pure-root, retabulated-root, and fallback strata; give per-design counts and medians, absolute producer times, process peak working sets, and ABC wall/diagnostic times separately. The 71 cases are not independent draws. Failures and missing repetitions remain visible in the denominator; no favorable subset replaces the sole failed synthetic primary result. Later natural families, ROBDD/generic-folding controls, prepared reuse, dense outputs, and fully matched startup/memory contracts require separately frozen work.
