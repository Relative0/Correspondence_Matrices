# Natural-circuit correctness gate, run 001

Fixed on 2026-09-26 before the first CM compilation of the admitted EPFL cases. This gate is **not a natural performance study** and cannot change the negative synthetic v4 primary finding. The 71 cases are exactly those in `NATURAL_CASES.jsonl`; no case, unsupported result, exception, or timeout may be dropped. The original 2,861-output screen and 20 source files remain the denominator for admission.

For each case, reconstruct the frozen translated AST from the original BLIF. Use one fresh Python process with a 60-second timeout. The assignment bit at integer position `k` uses support variable `j` = bit `j` of `k`; pass the reversed `x` variable list to the repository's MSB-first packed backends. Compare the direct identity-memoized packed AST, ordinary CM IR packed evaluation, and ABC's `read_blif; strash; dc2; write_aiger` AIG truth table exhaustively to the original BLIF digest. Request `pure_structural`, `hybrid`, and `retabulate` pair tokens using row `x0` and remaining variables as columns; report every root outcome. If a token exists, evaluate it across the entire source support and require agreement. Token production here is checked for correctness and prevalence only, never timed. Ordinary CM IR is checked even if a pair token exists.

Before invoking the first pair compiler, `natural_correctness.py prepare` records SHA-256 and byte length of the protocol, harness, translation, admission, source snapshot, ABC binary, AIG validator and all 71 AIGs; it creates an empty append-only `CORRECTNESS.jsonl`. `natural_correctness.py run` verifies those inputs, runs all 71 cases sequentially, and appends the complete case result or failure. The only passing gate is 71/71 cases with no truth disagreement, process exception, or timeout; unexpected outcomes are reported, not silently filtered. There is no null-hypothesis test or timing estimate. A later measured natural run needs its own execution freeze fixing arms, cache policy, calibration, repetitions, memory, schedule, analysis, environment, and initially empty measurement files.
