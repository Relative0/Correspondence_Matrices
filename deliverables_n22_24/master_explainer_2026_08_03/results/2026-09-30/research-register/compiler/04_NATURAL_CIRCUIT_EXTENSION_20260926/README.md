# Natural-circuit admission for the CM compiler study

This folder extends the completed synthetic v4 study in `../03_STUDY_DESIGN_20260926/`. It contains a **frozen natural admission and correctness run, not a measured natural-circuit performance result**. The v4 primary utility test failed and no natural result may replace it.

The source is the 20 **original** arithmetic and random/control EPFL BLIFs at Git commit `0060e156826e733d69bf5b3322d1bdd0d03a1f9a`, with the copied MIT notice. [Admission rules](NATURAL_ADMISSION_RULES.md) fixed primary-output selection before any CM pair compilation. [The screen](NATURAL_ADMISSION.json) covers all 2,861 original primary outputs: 71 cases from nine designs passed the structural rule, while 11 designs supplied no eligible primary output. The [71 case records](NATURAL_CASES.jsonl) include source and translated-AST hashes, support and sharing statistics, and exhaustive truth digests. No internal cone was substituted for an ineligible primary output. These design families overlap earlier P1–P14 work, so this cohort is not an uninspected-family holdout.

The [upstream verification](UPSTREAM_VERIFICATION.json) matches every copied BLIF to the pinned Git blob. [Translation validation](NATURAL_VALIDATION.json) checked all 71 translated ASTs exhaustively against their source BLIF truth tables. The [one-output cone exports](CONES_MANIFEST.json) were independently checked for source truth equivalence.

On Windows, verify the delivered admission record **in a project copy** with the pinned Python/NumPy environment described in `../03_STUDY_DESIGN_20260926/README.md`:

```powershell
python verify_natural_admission.py
git clone --filter=blob:none --no-checkout https://github.com/lsils/benchmarks.git epfl-upstream
python verify_epfl_upstream.py --repo .\epfl-upstream
```

The original protocol v3 requires an ABC-compatible AIG arm for the translatable natural subset. [The local ABC tool provenance](ABC_TOOL_PROVENANCE.json) pins the official [YosysHQ OSS CAD Suite Windows release](https://github.com/YosysHQ/oss-cad-suite-build/releases/tag/2026-07-29), its installer SHA-256, the extracted executable and five DLL hashes, and the ABC component source commit recorded in that release's `LICENSE.abc`. The tool reports ABC 1.01 compiled July 29, 2026. A two-input AND BLIF passed `read_blif; strash; dc2; write_aiger` and AIGER truth-table validation. `verify_abc_tool.py` checks the delivered executable and its dependencies without requiring the large installer. [The ABC AIG gate](ABC_AIG_VALIDATION.json) converted all 71 frozen cones with `strash; dc2`; all 71 AIG truth tables matched their original BLIFs. A direct MSVC build of a newer Berkeley ABC commit was attempted but failed in Windows-incompatible optional C++ modules; it is not the study tool.

Before the first CM call, the [correctness protocol](NATURAL_CORRECTNESS_PROTOCOL.md) and [run freeze](run_natural_correctness_001/FREEZE.json) fixed the 71 cases, source closure, ABC tool, AIG outputs, strategies, timeout, and initially empty result file. The [raw per-case outcomes](run_natural_correctness_001/CORRECTNESS.jsonl) and [summary](run_natural_correctness_001/SUMMARY.json) show 71/71 exhaustive agreements among original BLIF, translated AST, direct packed, ordinary CM IR, ABC AIG, and every returned pair token. A separate read-only recount (`python verify_natural_correctness.py`) found four pure structural roots, one full-root retabulation, and 66 ordinary fallbacks under `hybrid`; the four pure roots and the retabulated root are the five two-support cases. These counts describe the selected cohort only. **No natural arm was timed.**

The ABC AIG conversion can be reproduced in a clean project copy after removing the copied `aig_outputs/` directory and `ABC_AIG_VALIDATION.json`, using `python validate_abc_aig.py`. The frozen correctness run can likewise be reproduced in a copy after removing the copied `run_natural_correctness_001/` directory, then running `python natural_correctness.py prepare` and `python natural_correctness.py run`. Do not alter the original frozen files.

Before any natural-case performance measurement, freeze the exact row/column layout, competing arms, cache policy, calibration, repetitions (at least 15 per natural case), power/affinity state, memory measurement, and analysis with initially empty result files. Report ABC import/construction/optimization/query separately and retain unsupported cases and all fallbacks. The full protocol v3 also includes generated, sharing, reuse, output, ROBDD and other secondary cells; this folder does not claim to finish those cells or historical P14 runtime identity. The local ABC executable is included for verification, but public redistribution of its DLLs still needs license review.
