Verified October CPU pilots

Reviewed 14 October 2026. Two bounded synthetic development pilots completed: 112 valid cells and 56 matching pairs in each. These are engineering observations, not confirmation of a general CM speedup.

What changed and what the evidence supports

  • shared dag: The shared-DAG fixture has substantially lower current compiler/cache phase costs. This does not establish an end-to-end advantage on all formulas.
  • negative control: The unshared tree has higher current compile/cache phase costs; retain this tradeoff when selecting workloads.
  • packed: At width 22 CM residual preparation/query phases cost less than full cofactor preparation/query in this fixture. Width 12 has a different query-phase ranking.
  • support limit: P2 uses four active source variables; six fixed axes yield four distinct influential contexts repeated sixteen times in q64. It does not establish broader backend crossover thresholds.
  • windows layout: Windows cycled unused residual axes; WSL successor moves both active residual axes. Analytical hashes verify the new ordered packed outputs.
  • cross platform: The WSL scalar oracle memoizes shared identities and P2 order differs; do not pool platforms or attribute the timing change solely to Linux.
  • whole task: Fresh imports, independent validation, process startup and concurrent host workload dominate many full-lifecycle results. Component benefits are not whole-task guarantees.
  • prior results: The separately published 74181 CM/CSE schedule did not confirm improvement. The separate Bucket/CUDD result favored Bucket on one case with a deadline amendment.
  • unrun: P3 dense/parallel, P5 GF2/T3, optional native routes and broader real-workload confirmation were not executed by these pilots.
  • next: Focused packed-backend crossover preparation has started; no new crossover timings or dispatch policy are reported.

Checks, limits and reproducibility

Each pilot used one logical CPU and an enforced 2 GiB experiment limit, with 20-minute elapsed/core ceilings and verified cleanup. Independent verifiers checked the complete paired outputs and analytically verified 80 packed-query/count cells per pilot. P1 workers checked compiled truth values independently; post-run pairing does not reconstruct canonical keys anew. Windows committed memory and Linux cgroup memory are different metrics.

Downloaded trials are sanitized numeric evidence. Their checksums differ from the original raw-record hashes because operational metadata was removed. The frozen source download is a source/workload subset, not a bundled operating system, ready-made execution grant or turnkey runtime. Review and authorize bounds before reproduction.
